## 1. Document Vault Storage Architecture

- **Private Buckets**: `candidate-cv`, `candidate-identity`, `candidate-certificates`.
- **Upload Path Construction**: Object paths are formatted as `{candidateId}/{docType}/{timestamp}_{cleanFileName}` in [storage.service.ts](file:///c:/Users/IBZ/Downloads/behumbleandgrow/src/services/storage.service.ts).
- **Signed URL Expiration**: Documents are accessed via temporary 30-minute signed URLs (`expiresInSeconds = 1800`) generated by `createSignedUrl`. Public document links are prohibited.
- **File Validation**: Enforces maximum 10MB file size (`MAX_FILE_SIZE_BYTES`) and MIME type validation (`ALLOWED_MIME_TYPES = ['application/pdf', 'image/jpeg', 'image/png']`).
