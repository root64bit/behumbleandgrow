# 12 — Candidate Timelines & History Audit

- **Application Timeline**: Renders chronological stage events (Applied -> Under Review -> Interview Scheduled -> Offer Issued -> Placement Active). Internal recruiter notes are excluded.
- **Interview History**: Displays attendance confirmations and reschedule request history with server timestamps.
- **Offer Decision History**: Displays formal offer decision events (Offered, Accepted, Declined) with digital acceptance declarations timestamped in UTC.
- **Placement Roadmap**: Renders official relocation milestones (Work Permit, Entry Permit, Flights, Housing) separated from candidate travel-readiness acknowledgements.
