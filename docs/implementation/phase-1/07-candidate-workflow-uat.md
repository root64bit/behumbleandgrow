# 07. Candidate Workflow UAT Report

## End-to-End Candidate Lifecycle
1. Pre-Screening: Eligibility checked at `/eligibility`.
2. Profile Completion: Personal info, work experiences, education records, skills, languages persisted to database.
3. Private Documents: CV and Passport uploaded and metadata stored.
4. Job Application: Browse published active requisitions, submit application with unique reference `APP-2026-XXXX`.
5. Status Updates: Candidate views real-time status updates in dashboard without internal notes exposure.
