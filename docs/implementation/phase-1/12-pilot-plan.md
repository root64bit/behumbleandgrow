# 12. Controlled Candidate Pilot Plan

## Pilot Scope & Guidelines
- Target Cohort: 10–20 invited candidate test users.
- Environment: Vercel Staging (`https://behumbleandgrow-staging.vercel.app`).
- Fee Structure: **£15 application fee completely disabled** (`VITE_APPLICATION_FEE_ENABLED=false`).
- Candidate Notice: Prominently displays: `"Application fee disabled during the closed technical pilot."`
- Incident Protocol: Daily triage of candidate issues and fast candidate data deletion mechanism upon request.
