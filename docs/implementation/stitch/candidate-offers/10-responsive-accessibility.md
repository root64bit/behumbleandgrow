# Responsive & Accessibility Compliance — Phase A8

## Viewport Coverage
- Tested across viewports: 320px, 375px, 390px, 430px, 768px, 1024px, 1440px.

## Accessibility (WCAG 2.2 AA)
- Single `<h1>` title per page (`Conditional Offers`).
- Keyboard operable tabs and search controls.
- Distinct badges for lifecycle status vs decision state.
- Expiry text clearly formatted without relying solely on color.
