# Responsive & Accessibility Compliance — Phase A9

## Viewport Coverage
- Tested across viewports: 320px, 375px, 390px, 430px, 768px, 1024px, 1440px.

## Accessibility (WCAG 2.2 AA)
- Single `<h1>` title per page (`Conditional Offer Details`).
- Modals trap focus and close on Escape key.
- Declaration checkboxes explicitly labeled.
- High-contrast badges for offer status vs candidate decision.
