# Responsive & Accessibility Compliance

## Responsive Adaptations
- Tested across viewports: 320px, 375px, 390px, 430px, 768px, 1024px, 1440px.
- Mobile viewports utilize horizontal scrolling pill tabs and single-column application cards.
- Desktop viewports (1440px) utilize 5-column metric summary grids and multi-column action layouts inside `CandidateLayout`.

## Accessibility (WCAG 2.2 AA)
- Single `<h1>` title per page.
- Keyboard navigation across tabs, buttons, and link cards.
- ARIA live region support for filter updates and search results.
