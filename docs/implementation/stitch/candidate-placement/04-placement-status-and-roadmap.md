# Placement Status & Roadmap — Candidate Placement

## Canonical Placement Statuses
- `not_started`: Not Started
- `awaiting_candidate_action`: Action Required
- `documents_in_progress`: Documents in Progress
- `employer_processing`: Employer Processing
- `work_permit_in_progress`: Work Permit in Progress
- `visa_in_progress`: Visa Process in Progress
- `medical_in_progress`: Medical Process in Progress
- `travel_preparation`: Travel Preparation
- `accommodation_preparation`: Accommodation Preparation
- `onboarding_in_progress`: Employer Onboarding
- `completed`: Placement Completed
- `paused`: Paused
- `cancelled` / `unsuccessful`: Closed

## Roadmap Progress Calculation
- Progress percentage is computed as `completedRequiredStages / totalApplicableRequiredStages * 100`.
- Optional or not-applicable stages are excluded from the required total denominator.
