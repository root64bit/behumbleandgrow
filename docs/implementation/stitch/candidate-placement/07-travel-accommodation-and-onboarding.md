# Travel, Accommodation & Onboarding — Candidate Placement

## Flight & Itinerary Security
- Flight booking reference and travel details display ONLY when `flight_confirmed = true`. Prior to issuance, a safe locked state (`"Awaiting Visa Approval"`) is presented.

## Accommodation & Housing Security
- Accommodation details display general location (`Dubai, UAE`) and housing type, masking private landlord or residence contacts.

## Employer Onboarding
- Start date is marked `"To Be Confirmed Post-Arrival"` until trusted status confirms official date.
