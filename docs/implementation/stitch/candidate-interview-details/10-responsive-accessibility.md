# Responsive & Accessibility Compliance — Candidate Interview Details

## Responsive Adaptations
- Tested across viewports: 320px, 375px, 390px, 430px, 768px, 1024px, 1440px.
- Mobile viewports (390px) display full single-column cards and bottom sheet modal.
- Desktop viewports (1440px) render a centered max-w-lg container layout.

## Accessibility (WCAG 2.2 AA)
- Single `<h1>` title per page (`Interview #...`).
- Back button labeled `aria-label="Back to My Interviews"`.
- Keyboard accessible preparation checklist & dialogs.
- High-contrast badges for status and dual time display.
