# Preparation Checklist & Required Documents

## Bento-Style Preparation Checklist
- Interactive checklist (`Review Case Study & Role`, `Tech Check`, `Questions for Employer`).
- Interactive toggle state stored per candidate session.

## Required Documents Integration
- Integrates status cards for required candidate documents (`Updated Portfolio`, `Valid Passport Photo ID`).
- Provides deep link CTA to Document Vault (`/candidate/documents`).
